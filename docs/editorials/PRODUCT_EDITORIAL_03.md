# Product Editorial 03 — CONTINUITY

## Core message

**One Production Object. Multiple Views. One Continuous Story.**

This editorial is built entirely from real ATRAKTOR runtime screenshots.

It follows one creative-production path:

```text
Conversation
    ↓
Shot
    ↓
First Frame
    ↓
Motion
    ↓
Continuity
```

## Why this matters

The screenshots demonstrate that creative decisions do not remain trapped inside a conversation.

They become part of a real Shot Object. The same object then carries:

- the approved First Frame;
- Motion parameters;
- Production state;
- Continuity source;
- future handoff information.

The work continues because the context survives.

`assets/editorial/product-editorial-03-runtime/`
